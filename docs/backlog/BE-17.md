# BE-17 — Sentence and word timestamps for Listening transcripts

- **Type / branch:** `feat` / `feat/transcript-alignment`
- **Lane:** be
- **Depends on:** BE-11
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :backend:test :tools:content-import:test`

## Goal
Every Listening transcript is split into sentences with exact start/end times, which intensive listening and dictation need.

## Scope
- `core/model`: `TranscriptSentence(index, speaker?, text, startSeconds, endSeconds, words: List<TimedWord>)` per section; update the Listening schema and the original sample (hand-timed).
- `align --test <id>` command in `tools/content-import`: runs `whisper-cli` (whisper.cpp, local, `brew install whisper-cpp`, model path from `WHISPER_MODEL`) with word timestamps on each section's audio, then aligns the book transcript to the recognised words (normalised tokens, dynamic-programming alignment tolerant to recognition errors) and writes sentence and word times into the test JSON in `CONTENT_DIR`.
- When the transcript is missing, `--from-audio` uses the recognised text as the transcript and marks it `machineTranscribed`.
- Sentence splitting handles abbreviations, numbers, times and speaker labels.
- Report sentences with low alignment confidence for manual checking; `validate` checks sentences are ordered, non-overlapping and inside the audio duration.
