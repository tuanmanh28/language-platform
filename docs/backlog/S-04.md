# S-04 — Render every Compose preview to screenshots

- **Type / branch:** `test` / `test/compose-screenshots`
- **Lane:** core
- **Depends on:** S-03
- **Verify:** `./gradlew spotlessCheck :ui-compose:screenshots`
- **Reviews:** code-reviewer

## Goal
Designers and the design reviewer can see every screen and component without running the app.

## Scope
- Roborazzi with ComposablePreviewScanner (latest stable versions) on the `ui-compose` JVM target: every `@Preview` is rendered to `ui-compose/build/screenshots/<Preview>_<variant>.png`.
- Variants: phone (390×844 dp) and desktop (1280×800 dp), light and dark, font scale 1.0 and 2.0 for screens.
- Gradle task `:ui-compose:screenshots`; CI uploads the folder as an artifact.
- A `@LpPreviews` multi-preview annotation producing the variants above.

## Rules
- Latest stable libraries, looked up per `gradle-dependency`.

## Out of scope
Pixel-diff verification against golden images (later).

## Acceptance criteria
- Running the task twice is deterministic; existing previews render without errors.

## Definition of done
- Verify command passes and every review approves.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `test/compose-screenshots` as `test: <summary>` (no task id in the message).
