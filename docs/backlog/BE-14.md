# BE-14 — Writing prompts and submissions

- **Type / branch:** `feat` / `feat/writing-submissions`
- **Lane:** be
- **Depends on:** BE-09
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :core:exam-engine:jvmTest :backend:test`

## Goal
Store Writing prompts and the owner's essays so they can be graded.

## Scope
- `core/model`: `WritingPrompt(id, module, task: TASK_1_ACADEMIC | TASK_1_GENERAL | TASK_2, instructions, imageUrl?, minWords, minutes)`, `WritingSubmission(id, promptId, text, wordCount, submittedAt, status)`.
- Prompts: original public samples in `content/writing/`, private ones from `CONTENT_DIR/writing/` (BE-09 visibility rules; images stored like audio).
- Migration: `writing_prompts`, `writing_submissions` (user id, prompt id, text, word count, status `PENDING|GRADING|GRADED|FAILED`, timestamps).
- Auth-only API: `GET /api/v1/writing/prompts`, `POST /api/v1/writing/submissions`, `GET /api/v1/writing/submissions` (history), `GET /api/v1/writing/submissions/{id}`.
- Word count follows IELTS counting (numbers and hyphenated words count as one) in `core/exam-engine` with tests.

## Rules
- Real IELTS/Cambridge material never enters git, tests, fixtures, logs or commit messages. Tests use small original fixtures you write yourself.
- No secret is needed to finish: anything that talks to an external service sits behind an interface with a fake used in tests.

## Out of scope
Grading (BE-15).

## Acceptance criteria
- Route and repository tests; users only see their own submissions.

## Definition of done
- Verify command passes and the code review approves.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `feat/writing-submissions` as `feat: <summary>` (no task id in the message).
