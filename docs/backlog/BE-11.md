# BE-11 — Content import tool: extract, validate, seed

- **Type / branch:** `feat` / `feat/content-import-tool`
- **Lane:** be
- **Depends on:** BE-09, BE-10
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :backend:test :tools:content-import:test`

## Goal
Turning a PDF or audio file the owner has into a private test takes minutes, not hours.

## Scope
- New JVM module `tools/content-import` (Kotlin, `application` plugin, latest stable deps) runnable as `./gradlew :tools:content-import:run --args="<command> …"`.
- `extract <file.pdf> [--pages 10-25] [--ocr]`: text per page with Apache PDFBox into `CONTENT_DIR/work/<name>/page-NNN.txt`; `--ocr` renders pages to images and runs the `tesseract` CLI when installed (clear message with `brew install tesseract` otherwise). Also accepts saved `.html` pages (jsoup) for official online samples.
- `audio <file.mp3> --test <id> --section <n>`: copies into `CONTENT_DIR/audio/<id>/section-<n>.mp3` and records the duration (via `ffprobe` when installed, otherwise asks for `--duration`).
- `validate <file.json>`: validates against `content/schema/*.schema.json` (latest stable JSON Schema validator) plus semantic checks: question numbers 1..40 without gaps, every answer non-empty, every evidence quote found verbatim in its paragraph/transcript, choice answers exist in the options.
- `seed`: runs the backend seeding for `CONTENT_DIR` against the configured database.
- Never writes inside the repository; refuses a `CONTENT_DIR` inside the repo.

## Rules
- Real IELTS/Cambridge material never enters git, tests, fixtures, logs or commit messages. Tests use small original fixtures you write yourself.
- No secret is needed to finish: anything that talks to an external service sits behind an interface with a fake used in tests.

## Out of scope
The Claude Code skill that structures extracted text (BE-12).

## Acceptance criteria
- Tests with small original fixtures (a 2-page PDF generated in the test, a hand-written JSON) cover extract, validate errors and the repo-path guard.

## Definition of done
- Verify command passes and the code review approves.
- Follows `CLAUDE.md` and the skills.
