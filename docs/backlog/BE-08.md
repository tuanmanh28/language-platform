# BE-08 — Listening content model, API and audio storage

- **Type / branch:** `feat` / `feat/be-08-listening-api`
- **Lane:** be
- **Depends on:** BE-03
- **Verify:** `./gradlew :core:model:jvmTest :core:exam-engine:jvmTest :shared:jvmTest :backend:test`

## Goal
Support IELTS Listening tests end to end on the backend.

## Scope
- `core/model`: `ListeningTest` (4 sections, each with `audioUrl`, `durationSeconds`, optional `transcript` with timestamps, and question groups reusing existing question types; add `form_completion` and `map_labelling` only if they fit the existing model cleanly).
- `core/exam-engine`: `ListeningScorer` using `BandScale.listeningBand`.
- JSON Schema `content/schema/listening-test.schema.json` + one original sample in `content/listening/` (audio URL may point to a placeholder; note it in the summary).
- Migration + `listening_tests` table, seeding (extend BE-03's mechanism), `GET/POST /api/v1/listening/tests...` mirroring Reading.
- Audio storage: config for a public base URL (Cloudflare R2 / CDN); the API returns absolute URLs.

## Acceptance criteria
- Tests for the scorer, schema/sample consistency (like `BundledContentTest`) and the API.
