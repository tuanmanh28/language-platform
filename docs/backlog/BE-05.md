# BE-05 — Attempts sync API

- **Type / branch:** `feat` / `feat/be-05-attempts-sync`
- **Lane:** be
- **Depends on:** BE-03, BE-04
- **Verify:** `./gradlew :backend:test`

## Goal
Store practice attempts on the server so progress survives reinstalling and syncs between devices.

## Scope
- `POST /api/v1/attempts` (auth): body `{clientId, testId, answers, createdAt}`; the server re-scores with `ReadingScorer` (never trust client scores) and stores it. Idempotent on `clientId` (add a unique column via a new migration).
- `GET /api/v1/attempts?since=<timestamp>&limit=` (auth): the user's attempts, newest first, cursor-friendly.
- Add request/response models to `core/model` so the apps can reuse them.

## Acceptance criteria
- Tests: idempotent re-post, server-side scoring overrides client values, users only see their own attempts.
