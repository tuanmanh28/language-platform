# BE-03 — Serve Reading tests from the database with content seeding

- **Lane:** be
- **Depends on:** BE-02
- **Verify:** `./gradlew :backend:test`

## Goal
Reading tests come from PostgreSQL instead of the bundled list.

## Scope
- `DatabaseContentStore : ContentStore` backed by `reading_tests` (content stored as the `ReadingTest` JSON). Only `published = true` rows are listed.
- Seeding: a Gradle task `:backend:seedContent` (or a CLI entry point) that upserts every `content/reading/*.json` into the DB, bumping `version` when content changed. Idempotent.
- Select the store by config: `CONTENT_SOURCE=db|bundled` (default `db`, tests may use `bundled`).
- `ETag`/`Cache-Control` on GET endpoints using `version`.

## Acceptance criteria
- Integration test: seed → list → get → submit returns the same result as `ReadingScorer` on the bundled sample.
- Running the seed twice produces no duplicate rows and no version bump.
