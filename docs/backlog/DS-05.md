# DS-05 — Vocabulary, flashcards and spaced repetition

- **Type / branch:** `docs` / `docs/design-vocabulary`
- **Lane:** design
- **Depends on:** DS-01
- **Verify:** `test -s docs/design/vocabulary/README.md && ls docs/design/vocabulary/mockups/*.html`

## Goal
Saving and reviewing words is quick and pleasant every day.

## Scope
- Save-word sheet from any text; decks list and deck detail; card editor.
- Review session with flip animation, rating buttons showing intervals, swipe gestures, undo; Learn, Write, Match and Test modes like Quizlet.
- Statistics: heatmap, retention, forecast; settings for limits and retention with workload preview.
- Deliverables: `docs/design/vocabulary/README.md` and `docs/design/vocabulary/mockups/*.html` as described in the `ux-design` skill.

## Rules
- Follow the `ux-design` skill: Apple-quality bar — beautiful, simple, friendly, calm, smooth motion.
- Design only: no app code changes. Mockups are self-contained HTML using our tokens.
- Original work: no copied screenshots or assets from other apps; reference them by link.

## Out of scope
Implementation (AND-05, AND-15, AND-16, AND-17).

## Acceptance criteria
- Every screen has all states, Vietnamese copy, accessibility notes and its motion spec.
- Mockups open in a browser with light/dark and phone/desktop frames.
