# BE-18 — Dictionary lookup for flashcards

- **Type / branch:** `feat` / `feat/dictionary-lookup`
- **Lane:** be
- **Depends on:** BE-04
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :core:exam-engine:jvmTest :backend:test`

## Goal
Adding a word fills IPA, audio, meanings and examples automatically.

## Scope
- `GET /api/v1/dictionary/{word}` (auth): IPA (UK/US), audio URLs, part of speech, English definitions and examples from the Free Dictionary API (`dictionaryapi.dev`, Wiktionary data, CC BY-SA — show attribution) behind a `DictionarySource` interface.
- Vietnamese meaning, IELTS-style example sentence, collocations, word family and synonyms/antonyms from an `EnrichmentProvider` (Claude API, `ANTHROPIC_API_KEY` at runtime only; returns nothing without a key).
- Cache results in Postgres (`dictionary_entries`, migration) so each word is fetched once; per-user rate limit.

## Rules
- Real IELTS/Cambridge material never enters git, tests, fixtures, logs or commit messages. Tests use small original fixtures you write yourself.
- No secret is needed to finish: anything that talks to an external service sits behind an interface with a fake used in tests.
- UI uses design-system components only; user-facing strings in Vietnamese resources; all logic in `shared`/`core` with tests.

## Out of scope
Flashcard UI (AND-15).

## Acceptance criteria
- Route tests with fake source and provider: hit, miss, cache, provider unavailable.

## Definition of done
- Verify command passes and the code review approves.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `feat/dictionary-lookup` as `feat: <summary>` (no task id in the message).
