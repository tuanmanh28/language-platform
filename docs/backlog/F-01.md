## Goal
The Phase 1 scaffold was written without being compiled. Make every module compile and every existing test pass.

## Scope
- Fix compile errors, wrong imports, API mismatches and Gradle configuration issues across all modules.
- Keep library versions from `gradle/libs.versions.toml` unless a version truly does not exist or is incompatible; if you change one, explain why in the summary.
- Keep behaviour and public APIs the same; this is a fix-up task, not a redesign.
- If `configuration-cache` reports problems, fix them (do not just disable it).

## Out of scope
New features, UI changes, refactors beyond what is needed to compile.

## Acceptance criteria
- The verify command passes from a clean checkout.
- `cd app-apple && xcodegen && xcodebuild -scheme LanguagePlatformiOS -sdk iphonesimulator build` is attempted if Xcode is available; report the result (do not block on it).
- Summary lists every non-trivial fix.

## Definition of done
- Verify command passes.
- Follows `CLAUDE.md` (scope, architecture, tests, no AI attribution in commits).
- Committed on branch `fix/build-green` as `fix: <summary>` (no task id in the message).
