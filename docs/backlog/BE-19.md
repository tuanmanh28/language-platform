# BE-19 — Ingest a library of IELTS books: unpack, dedupe, OCR, audio

- **Type / branch:** `feat` / `feat/content-library-ingest`
- **Lane:** be
- **Depends on:** BE-11
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :backend:test :tools:content-import:test`

## Goal
Turn a folder of downloaded archives (zip/rar, nested, duplicated, mixed audio formats, scanned PDFs) into a clean, indexed source library ready for import.

## Scope
- `ingest <folder>`: unpack zip and rar recursively (`unar` or `7z`), detect duplicates by content hash, and lay files out as `CONTENT_DIR/sources/cam-<NN>/book.pdf` and `CONTENT_DIR/sources/cam-<NN>/audio/test-<t>/part-<p>.<ext>`. Book number and test/part come from file and folder names; the heuristics handle patterns such as `Test1 Part1`, `ielts15_test1_audio1`, `section1-part2` with non-Latin prefixes, `Tests1-4CD1Track_07` and one file per test.
- Ambiguous audio (CD track numbers, one file per test) is recorded as `unassigned` with its duration; BE-17 alignment later maps it to test/part by matching the audioscript, and splits single-file tests at the part boundaries.
- `audio normalize`: convert every part to AAC `.m4a` 64 kbps mono with loudness normalisation (ffmpeg `loudnorm`), keeping the original; record durations.
- `ocr --book cam-<NN> [--parallel n]`: detect whether each PDF page has a text layer (`pdftotext`); otherwise render at 300 dpi and OCR with `tesseract` (English), cache results per page so reruns are instant.
- Page classification per book (keywords and layout): test number and section (Listening, Reading passage n, Writing task n, Speaking), answer key, audioscripts, sample Writing answers with examiner comments. Store `CONTENT_DIR/sources/cam-<NN>/pages.json`.
- `crop --book cam-<NN> --page n --box x,y,w,h --out <name>.png`: cut figures (Writing Task 1 charts, maps and plans in Listening/Reading) from the rendered page.
- `inventory`: `CONTENT_DIR/sources/inventory.md` with, per book: PDF type (text/scan), pages, OCR status, tests found, answer key / audioscript / sample answers present, audio parts found, missing or unassigned, duplicates skipped.

## Rules
- Real IELTS/Cambridge material never enters git, tests, fixtures, logs or commit messages. Tests use small original fixtures you write yourself (generated PDFs, synthetic audio tones, invented file names).
- No secret is needed to finish: external binaries (tesseract, ffmpeg, unar, whisper-cli, claude) sit behind interfaces with fakes in tests and give an install hint when missing.
- Everything the tools write goes under `CONTENT_DIR`; refuse paths inside the repository.

## Out of scope
Structuring tests into JSON (BE-20 with the BE-12 skill).

## Acceptance criteria
- Tests with generated archives (nested zip, duplicate files, invented names for every pattern above), a generated 3-page PDF with and without a text layer and a synthetic tone as audio; classification tested on original fixture text.

- Verify command passes and the code review approves.
- Follows `CLAUDE.md` and the skills.
