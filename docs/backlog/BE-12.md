# BE-12 — Claude Code skill to import a full IELTS test

- **Type / branch:** `feat` / `feat/content-import-skill`
- **Lane:** be
- **Depends on:** BE-11
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :backend:test :tools:content-import:test`

## Goal
The owner can say "import Reading Test 2 from ~/Books/ielts-20.pdf" and get a validated private test with full explanations.

## Scope
- `.claude/skills/ielts-content-import/SKILL.md` (frontmatter `name`, `description` starting "Use when…"), following the format of the other skills.
- Workflow it prescribes: run `extract` → read the pages and the answer key → write Reading/Listening JSON into `CONTENT_DIR` (question types mapped to `QuestionType`, paragraph ids, answers incl. accepted variants) → write the BE-10 explanation for every question (Vietnamese text, evidence quote copied verbatim, paraphrase pairs, trap) → `validate` until clean → `seed`.
- Listening: uses the transcript from the book when present, `audio` command for each section, evidence as time ranges (estimate from transcript position when no timestamps exist and say so).
- Writing prompts and sample answers with examiner bands go to `CONTENT_DIR/writing/` and `CONTENT_DIR/calibration/` (formats from BE-14 and BE-16 once they exist; until then describe the planned layout).
- Hard rules in the skill: content stays in `CONTENT_DIR`, never in the repo or commits; only material the owner provides.
- Add the skill to the table in `CLAUDE.md`.

## Rules
- Real IELTS/Cambridge material never enters git, tests, fixtures, logs or commit messages. Tests use small original fixtures you write yourself.
- No secret is needed to finish: anything that talks to an external service sits behind an interface with a fake used in tests.

## Out of scope
Running it on real material (the owner does that).

## Acceptance criteria
- Dry run documented in the summary on a short original fixture: extract → JSON → validate passes.

## Definition of done
- Verify command passes and the code review approves.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `feat/content-import-skill` as `feat: <summary>` (no task id in the message).
