# BE-16 — Calibrate AI grading against examiner scores

- **Type / branch:** `feat` / `feat/grading-calibration`
- **Lane:** be
- **Depends on:** BE-15, BE-11
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :backend:test :tools:content-import:test`

## Goal
Measure how far AI bands are from examiner bands before trusting them.

## Scope
- Format `CONTENT_DIR/calibration/<id>.json`: prompt, essay, examiner bands per criterion and overall, examiner comment (from sample answers in the owner's books).
- `calibrate [--provider claude|fake] [--limit n]` command in `tools/content-import`: grades every sample, writes `CONTENT_DIR/reports/calibration-<date>.md` with mean absolute error per criterion and overall, share within ±0.5, the worst five essays and their differences.
- Document the agreed threshold in `docs/ROADMAP.md` gate for Phase 3 (overall MAE ≤ 0.5).

## Rules
- Real IELTS/Cambridge material never enters git, tests, fixtures, logs or commit messages. Tests use small original fixtures you write yourself.
- No secret is needed to finish: anything that talks to an external service sits behind an interface with a fake used in tests.

## Out of scope
Prompt tuning itself.

## Acceptance criteria
- Tests with the fake provider and original fixtures check the metrics and the report.

## Definition of done
- Verify command passes and the code review approves.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `feat/grading-calibration` as `feat: <summary>` (no task id in the message).
