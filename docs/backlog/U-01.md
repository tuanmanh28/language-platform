# U-01 — Upgrade the whole stack to the latest stable versions

- **Type / branch:** `update` / `update/latest-dependencies`
- **Lane:** core
- **Depends on:** F-01
- **Verify:** `./gradlew :core:model:jvmTest :core:exam-engine:jvmTest :shared:jvmTest :backend:test :app-android:assembleDebug :app-desktop:compileKotlin :shared:compileKotlinIosSimulatorArm64`

## Goal
Every tool and library is on its latest stable release before feature work continues.

## Scope
- Follow the `gradle-dependency` skill ("Upgrading the whole stack"): Gradle wrapper, Kotlin, AGP, Compose Multiplatform, then every entry in `gradle/libs.versions.toml`, the foojay plugin and GitHub Actions versions in `.github/workflows/`.
- Look every version up at its official source; do not rely on memory.
- Fix deprecations and migration notes instead of suppressing warnings. Keep the configuration cache green.
- Remove catalog entries that nothing uses.

## Out of scope
New libraries (they come with the tasks that need them), behaviour changes.

## Acceptance criteria
- Verify command passes; summary lists every upgrade (old → new) and any library that could not be upgraded and why.

## Definition of done
- Verify command passes.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `update/latest-dependencies` as `update: <summary>` (no task id in the message).
