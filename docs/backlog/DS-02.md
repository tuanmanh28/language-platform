# DS-02 — Information architecture, navigation and home

- **Type / branch:** `docs` / `docs/design-navigation-and-home`
- **Lane:** design
- **Depends on:** DS-01
- **Verify:** `test -s docs/design/navigation-home/README.md && ls docs/design/navigation-home/mockups/*.html`
- **Reviews:** design-reviewer

## Goal
The app opens on what to do today and every feature is one or two taps away.

## Scope
- Information architecture and tab structure (e.g. Hôm nay, Luyện đề, Từ vựng, Tiến độ, Tôi) with reasons; adaptive navigation (bottom bar, rail, sidebar on desktop).
- "Hôm nay" home: daily plan, continue where you left off, due flashcards, streak and weekly goal ring, weakest question type, quick dictation.
- Onboarding: target band, exam date, daily minutes, notification time — short, skippable.
- Progress screen and profile/settings, sign-in entry, offline banner, global search.
- Transition map between all top-level destinations.
- Deliverables: `docs/design/navigation-home/README.md` and `docs/design/navigation-home/mockups/*.html` as described in the `ux-design` skill.

## Rules
- Follow the `ux-design` skill: Apple-quality bar — beautiful, simple, friendly, calm, smooth motion.
- Design only: no app code changes. Mockups are self-contained HTML using our tokens.
- Original work: no copied screenshots or assets from other apps; reference them by link.

## Out of scope
Implementation (AND-19).

## Acceptance criteria
- Every screen has all states, Vietnamese copy, accessibility notes and its motion spec.
- Mockups open in a browser with light/dark and phone/desktop frames.

## Definition of done
- Verify command passes and every review approves.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `docs/design-navigation-and-home` as `docs: <summary>` (no task id in the message).
