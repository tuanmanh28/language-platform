# S-03 — Blank line between sibling UI elements

- **Type / branch:** `refactor` / `refactor/separate-sibling-ui-elements`
- **Lane:** core
- **Depends on:** R-01
- **Verify:** `./gradlew spotlessCheck :app-android:assembleDebug :app-desktop:compileKotlin`

## Goal
UI code reads as a list of clearly separated parts, per the "One blank line between siblings in UI code" rule in the
`code-conventions` skill.

## Scope
- Every composable in `ui-compose` and every SwiftUI view in `app-apple/Sources`: one blank line between sibling
  elements at the same level (state group, each effect, each back handler, each child composable or view).
- No blank line right after `{` or right before `}`.

## Out of scope
Any change other than blank lines.

## Acceptance criteria
- `git diff --ignore-blank-lines main...HEAD` is empty.

## Definition of done
- Verify command passes and the code review approves.
- Committed on branch `refactor/separate-sibling-ui-elements` as `refactor: <summary>` (no task id in the message).
