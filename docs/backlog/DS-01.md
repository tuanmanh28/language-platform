# DS-01 — Design direction and visual language

- **Type / branch:** `docs` / `docs/design-direction`
- **Lane:** design
- **Depends on:** —
- **Verify:** `test -s docs/design/direction/README.md && ls docs/design/direction/mockups/*.html`
- **Reviews:** design-reviewer

## Goal
Define how the app looks, feels and moves, so every later screen is consistent and Apple-quality.

## Scope
- Product principles and personality (friendly coach, calm exam room); voice and tone guide for Vietnamese copy with do/don't examples.
- Visual language: typography choice (open licence, full Vietnamese diacritics, type scale), colour system (brand accent, neutrals, semantic correct/wrong/warning/info, colour-blind check, full dark palette), spacing grid, radii, elevation and translucency, icon set, illustration style.
- Motion system: spring and duration tokens, screen transition patterns (push/pop, tab fade-through, sheets, shared elements), micro-interactions, haptics map, Reduce Motion fallbacks.
- Exact token changes for `design/tokens/*.json` and a component inventory: existing `Lp…` components to restyle, new ones needed, with states.
- Mockups: a style tile, the component sheet, and three sample screens (home, test room, flashcard) in phone and desktop frames, light and dark, with transitions animated.
- Deliverables: `docs/design/direction/README.md` and `docs/design/direction/mockups/*.html` as described in the `ux-design` skill.

## Rules
- Follow the `ux-design` skill: Apple-quality bar — beautiful, simple, friendly, calm, smooth motion.
- Design only: no app code changes. Mockups are self-contained HTML using our tokens.
- Original work: no copied screenshots or assets from other apps; reference them by link.

## Out of scope
Implementation (AND-18).

## Acceptance criteria
- Every screen has all states, Vietnamese copy, accessibility notes and its motion spec.
- Mockups open in a browser with light/dark and phone/desktop frames.

## Definition of done
- Verify command passes and every review approves.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `docs/design-direction` as `docs: <summary>` (no task id in the message).
