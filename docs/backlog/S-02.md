# S-02 — Reformat the codebase to 2-space indentation

- **Type / branch:** `refactor` / `refactor/two-space-indent`
- **Lane:** core
- **Depends on:** S-01
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :core:exam-engine:jvmTest :shared:jvmTest :backend:test :app-android:assembleDebug :app-desktop:compileKotlin`

## Goal
Every source file uses 2 spaces per indentation level, as `.editorconfig`, `app-apple/.swift-format` and the
`code-conventions` skill now require.

## Scope
- `./gradlew spotlessApply` for all Kotlin and Gradle files (ktlint reads `indent_size = 2` from `.editorconfig`).
- `bash scripts/format-swift.sh` for `app-apple/Sources`, then `xcrun swift-format lint --strict --recursive app-apple/Sources`.
- Re-indent the rest by hand where no formatter runs: `*.sq`/`*.sqm`, SQL migrations, XML resources and manifests,
  JSON content, YAML (workflows, `project.yml`, `docker-compose.yml`), shell scripts. Python stays PEP 8 (4 spaces).
- If a ktlint or swift-format setting still produces 4-space continuation indents, set it to 2 in the config.

## Out of scope
Any change other than whitespace and formatter configuration.

## Acceptance criteria
- `git diff -w main...HEAD` shows only formatter configuration changes.
- `spotlessApply` twice produces no diff; swift-format lint exits 0.

## Definition of done
- Verify command passes and the code review approves.
- Committed on branch `refactor/two-space-indent` as `refactor: <summary>` (no task id in the message).
