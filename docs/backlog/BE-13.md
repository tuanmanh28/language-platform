# BE-13 — Strategy tips per question type

- **Type / branch:** `feat` / `feat/question-type-tips`
- **Lane:** be
- **Depends on:** BE-10
- **Verify:** `./gradlew spotlessCheck :core:model:jvmTest :core:exam-engine:jvmTest :backend:test`

## Goal
Short, original strategy notes for every IELTS question type replace video lessons.

## Scope
- `core/model`: `QuestionTypeTip(type, title, summary, steps, commonTraps, example)`; JSON in `content/tips/<type>.json`, Vietnamese, written from scratch (original wording, original examples).
- Cover every `QuestionType` used by Reading and Listening.
- Schema + consistency test (every question type has a tip).
- `GET /api/v1/tips` and `GET /api/v1/tips/{type}`, public, cached with `ETag`.

## Rules
- Real IELTS/Cambridge material never enters git, tests, fixtures, logs or commit messages. Tests use small original fixtures you write yourself.
- No secret is needed to finish: anything that talks to an external service sits behind an interface with a fake used in tests.

## Out of scope
UI (AND-10).

## Acceptance criteria
- Consistency test fails when a new `QuestionType` has no tip.

## Definition of done
- Verify command passes and the code review approves.
- Follows `CLAUDE.md` and the skills.
- Committed on branch `feat/question-type-tips` as `feat: <summary>` (no task id in the message).
