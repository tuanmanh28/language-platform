# BE-04 — Firebase Auth token verification and users

- **Type / branch:** `feat` / `feat/firebase-auth`
- **Lane:** be
- **Depends on:** BE-02
- **Verify:** `./gradlew spotlessCheck :backend:test`

## Goal
Authenticate app users with Firebase ID tokens (Google / Apple / email sign-in happen in the apps).

## Scope
- Ktor `Authentication` with a bearer provider that verifies Firebase ID tokens (Firebase Admin SDK, or Google public keys + JWT verification). Project id from config `FIREBASE_PROJECT_ID`.
- Put verification behind an interface `TokenVerifier` so tests use a fake.
- On first authenticated request, upsert the user into `users`.
- `GET /api/v1/me` returns `{id, email, displayName}`.
- Reading list/detail/submit stay public; new user-specific endpoints require auth.

## Acceptance criteria
- Tests: missing token → 401, invalid token → 401, valid fake token → 200 and user row created once.
- README documents the env var and how to get the project id.
